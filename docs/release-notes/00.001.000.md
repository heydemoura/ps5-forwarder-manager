The first release of Forwarder Manager: create and edit home-screen forwarders on the console itself.

### Added
- A home screen that lists your forwarders, grouped in tabs by target app.
- Create and edit forwarders: display name, target app, title ID, ROM file and the exit-after-game option.
- Tile icons and backgrounds from SteamGridDB search or from an image file on the console, encoded to the formats the PS5 expects.
- Selection music from an .at9 file, previewed on the edit screen together with the background.
- A built-in, open-source launcher. Forwarders start their target without any other launcher payload, and start the launcher themselves when it isn't running.
- Forwarders follow the open PS5 Forwarder Format, so emulators can create and read the same tiles.
- Forwarders made by earlier tools are upgraded to the current forwarder program when the app starts.

### Requirements
- A jailbroken PS5 with elfldr.
- The PS5 Lapy JB daemon, for access to /data.
- ShadowMountPlus, to register the app and the forwarders it creates.

### Install
Unzip `PPSA99930.zip` and copy the `PPSA99930` folder to `/data/homebrew/`.
