Pick ProsperoEden games with their names and covers, including games kept in their own folders.

### Added

- **ProsperoEden game picker.** The Game row lists ROMs from ProsperoEden's game files folder, with their cached titles and covers. Selecting a game fills an empty display name and uses its cover as the tile icon, while keeping an icon you already chose. (#27)
- **Follow ProsperoEden's settings.** Reads `game_files` from `/data/prosperoeden/config/prosperoeden.json`, defaulting to `/data/prosperoeden`. Finds loose ROMs and games one folder down in `roms/`. Relative paths appear under the titles so games with the same name can be told apart. A file browser remains available for other ROMs. (#27)
- **ROM formats.** The picker recognizes `.nsp`, `.xci`, `.nsz` and `.xcz`. Compressed games require a ProsperoEden version that supports them. Recognizable update/DLC filenames and title-ID tags are excluded; encrypted package contents are not inspected, so add-ons with ambiguous names may still appear. (#27)

### Fixed

- **Forwarders for nested ProsperoEden games.** A game such as `roms/Mario Kart 8 Deluxe/Mario Kart 8 Deluxe.nsp` now keeps `Mario Kart 8 Deluxe/Mario Kart 8 Deluxe.nsp` in its launch arguments. Tiles keep working when the configured game files folder moves; ROMs selected outside that folder use their full path. Fixes #26. (#27)
  - To repair a tile created with a missing folder, edit it, select its game again, and save.
- **Reproducible builds.** Restored the pinned OpenGL SDK download through a mirror after the original repository became unavailable. Both original SHA-256 checks remain enforced. CI also runs the ProsperoEden library regression tests. (#27)

### Changed

- **SwanStationPS5 target name.** The target picker and home-screen tab now use the emulator's full name, SwanStationPS5. Its title ID and existing tiles are unchanged. (#25, by @darkxex)

### Thanks

### Requirements

- A jailbroken PS5 with elfldr on port 9021.
- ShadowMountPlus, to register the app and the forwarders it creates.

### Install

Unzip `PPSA99930.zip` and copy the `PPSA99930` folder to `/data/homebrew/`, replacing the old one. Your forwarders are kept. `SHA256SUMS` contains the ZIP's checksum.
