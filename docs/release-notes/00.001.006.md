Accept ProsperoEden's second title ID, and move the OpenGL SDK to a maintained mirror.

### Added

- **ProsperoEden ( Mirror ) target.** ProsperoEden ships under two title IDs; the target picker now offers `PPSA99016` as "ProsperoEden ( Mirror )" alongside the original `PPSA99008`. Both follow the same rules for launch arguments and the game list, so a forwarder can target whichever ProsperoEden is installed. (#35)

### Fixed

- **Reproducible builds.** The pinned OpenGL SDK download moved to the maintained darkxex/ps5-opengl mirror (SDK 1.0.2) after the previous mirror became unavailable. Both the archive and manifest SHA-256 checks remain enforced; the SDK layout and 1920x1080x60 display profile are unchanged. (#35)

### Requirements

- A jailbroken PS5 with elfldr on port 9021.
- ShadowMountPlus, to register the app and the forwarders it creates.

### Install

Unzip `PPSA99930.zip` and copy the `PPSA99930` folder to `/data/homebrew/`, replacing the old one. Your forwarders are kept. `SHA256SUMS` contains the ZIP's checksum.
